# Universal LPC equipment sources

Pinned source commit: `86a3719ee4a7e2e9fb27c7c152e29a741d3e930a`
Repository: https://github.com/LiberatedPixelCup/Universal-LPC-Spritesheet-Character-Generator

This directory contains **unaltered official LPC sprite sheet PNG files**. Each variant includes the native `walk`, `slash`, `halfslash`, `backslash`, and `combat_idle` pose sheets, in that order. Frame cells are **64 × 64** and pose rows are **north, west, south, east**.

- `helmet/iron`: `spritesheets/hat/helmet/bascinet/adult/` — authors bluecarrot16, ElizaWy, Sander Frenken (castelonia).
- `helmet/royal`: `spritesheets/hat/helmet/greathelm/male/` — author bluecarrot16.
- `armor/iron`: `spritesheets/torso/armour/plate/male/` — Napsio (Vitruvian Studio), JaidynReiman, bluecarrot16, Michael Whitlock (bigbeargames), Johannes Sjölund (wulax).
- `armor/royal`: `spritesheets/torso/armour/legion/male/` — Napsio (Vitruvian Studio), JaidynReiman, bluecarrot16, Nila122.

Full original metadata, available license options (including **OGA-BY 3.0**), authors and source URLs are copied unchanged to the `credits/` JSON files.

For complete license compliance when distributing or publishing this game, retain the official per-item attributions and honor the chosen original art license. These binary PNG assets were copied as-is from the original pinned Git repository. The code composes them over the existing LPC character sprites at the matching pose/frame; no hand-drawn coordinate approximations are used.
