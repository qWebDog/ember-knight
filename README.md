# EMBER — окно создания персонажа

Статическая mobile-first web app для Telegram. Запуск: любой HTTP-сервер с корнем `dist/`.

- Шесть оригинальных палитр Universal LPC, голова и тело без экипировки.
- Четыре направления, idle-анимация, управление с клавиатуры.
- Создание персонажа и восстановление облика из localStorage (`ember.character.v1`).
- Поддержка Telegram WebApp ready/expand, цветов и haptic feedback. Работает и в обычном браузере.
- Сохранение пока локальное. Backend, бот Telegram и геймплей не подключены.

Атрибуция и лицензии спрайтов: `dist/assets/characters/CREDITS.txt`.

## Правило первого экрана

Экран создания целиком помещается в доступную высоту Telegram/browser viewport без прокрутки страницы или панели. Высота отслеживает Telegram `viewportChanged`, `visualViewport.resize` и поворот устройства. Основные элементы — персонаж, поворот, шесть оттенков и кнопка создания — остаются на экране. Второстепенная информация на компактных экранах доступна в справке. Сцена занимает остаток высоты, в landscape используется двухколоночная компоновка.

Целевые размеры: 320×568, 390×667, 390×844, 667×375, 844×390, 1366×768, 1440×900.
